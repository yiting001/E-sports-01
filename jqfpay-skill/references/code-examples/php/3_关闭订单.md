# 关闭订单

API路径：`api/pay/close`

在线文档：https://doc.jeequan.com/#/integrate/jqf/api/41

## PHP 示例

```php
<?php
/**
 * 计全付 关闭订单 - PHP curl 示例
 * 关闭未支付的订单，释放资源
 */

$apiBase = 'https://your-jqf-domain.com';
$appId   = '6064c5c8f3e4a24e5b8e1a3c';
$mchNo   = 'M1640000001';
$apiKey  = 'your_api_key_here';

function md5Sign(array $params, string $apiKey): string
{
    $filtered = array_filter($params, function ($v) {
        return $v !== null && $v !== '';
    });
    ksort($filtered, SORT_STRING | SORT_FLAG);
    $parts = [];
    foreach ($filtered as $k => $v) {
        $parts[] = $k . '=' . $v;
    }
    $signStr = implode('&', $parts) . '&key=' . $apiKey;
    return strtoupper(md5($signStr));
}

// ========== 构造请求参数 ==========
$params = [
    'mchNo'      => $mchNo,
    'appId'      => $appId,
    'mchOrderNo' => 'ORDER202605211430001234',  // 商户订单号（与 payOrderId 二选一）
    // 'payOrderId' => 'P2026052114300000001',  // 或使用支付系统订单号
    'version'    => '1.0',
    'signType'   => 'MD5',
    'reqTime'    => date('YmdHis'),
];

$params['sign'] = md5Sign($params, $apiKey);

// ========== 发送请求 ==========
$ch = curl_init();
curl_setopt_array($ch, [
    CURLOPT_URL            => $apiBase . '/api/pay/close',
    CURLOPT_POST           => true,
    CURLOPT_POSTFIELDS     => json_encode($params),
    CURLOPT_HTTPHEADER     => [
        'Content-Type: application/json',
        'Accept: application/json',
    ],
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_SSL_VERIFYPEER => false,
    CURLOPT_TIMEOUT        => 30,
]);

$response = curl_exec($ch);
curl_close($ch);

$result = json_decode($response, true);

if (($result['code'] ?? -1) === 0) {
    echo "订单关闭成功\n";
} else {
    echo "关闭失败: " . ($result['msg'] ?? '未知错误') . "\n";
}
```

## 成功响应示例

```json
{
  "code": 0,
  "msg": "SUCCESS",
  "data": {
    "payOrderId": "P2026052114300000001",
    "mchOrderNo": "ORDER202605211430001234",
    "state": 4
  },
  "sign": "C3D4E5F6A7B8C9D0E1F2A3B4C5D6E7F8"
}
```

```json
  "data": null,
  "sign": null
}
```
