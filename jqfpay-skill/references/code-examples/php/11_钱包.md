# 钱包

API路径：

| 接口 | API路径 |
|------|---------|
| 创建钱包 | `api/wallet/user` |
| 绑定银行卡 | `api/wallet/bankcard/bind` |
| 查询钱包用户 | `api/wallet/user/query` |
| 钱包变动明细 | `api/wallet/user/changeDetails` |
| 钱包提现 | `api/wallet/cashout` |
| 查询钱包提现 | `api/wallet/cashout/query` |
| 钱包转账 | `api/wallet/transfer` |
| 查询钱包转账 | `api/wallet/transfer/query` |

## PHP 示例

function md5Sign(array $params, string $apiKey): string
{
    $filtered = array_filter($params, function ($v) {
        return $v !== null && $v !== '';
    });
    ksort($filtered, SORT_STRING | SORT_FLAG);
    $parts = [];
    foreach ($filtered as $k => $v) {
        $parts[] = $k . '=' . $v;
    }
    $signStr = implode('&', $parts) . '&key=' . $apiKey;
    return strtoupper(md5($signStr));
}

function postJson(string $url, array $params): array
{
    $ch = curl_init();
    curl_setopt_array($ch, [
        CURLOPT_URL            => $url,
        CURLOPT_POST           => true,
        CURLOPT_POSTFIELDS     => json_encode($params),
        CURLOPT_HTTPHEADER     => [
            'Content-Type: application/json',
            'Accept: application/json',
        ],
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_SSL_VERIFYPEER => false,
        CURLOPT_TIMEOUT        => 30,
    ]);
    $response = curl_exec($ch);
    curl_close($ch);
    return json_decode($response, true);
}
