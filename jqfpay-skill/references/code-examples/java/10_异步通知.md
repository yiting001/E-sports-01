# 异步通知

计全付在支付、退款、转账完成后，会向商户配置的 `notifyUrl` 发送异步通知。商户需要验签并做幂等处理。

通知类型：
- 支付结果通知
- 退款结果通知
- 转账结果通知

## SDK调用示例（Java）

### 统一异步通知处理（Spring Boot Controller）

```java
import com.jeequan.jeepay.model.PayOrderNotifyResModel;
import com.jeequan.jeepay.util.JeepayNotifyKit;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

import javax.servlet.http.HttpServletRequest;
import javax.servlet.http.HttpServletResponse;
import java.io.IOException;
import java.util.concurrent.ConcurrentHashMap;

@RestController
@RequestMapping("/notify")
public class NotifyController {

    @Autowired
    private HttpServletRequest request;
    @Autowired
    private HttpServletResponse response;

    // 简易幂等去重表（生产环境应使用 Redis 或数据库）
    private final ConcurrentHashMap<String, Boolean> processedOrders = new ConcurrentHashMap<>();

    /** 应用密钥（根据mchNo+appId查询对应密钥） */
    private String getAppSecret(String mchNo, String appId) {
        // 实际项目中从数据库或配置中查询
        return "yourAppSecret";
    }

    // ==================== 支付结果通知 ====================

    @PostMapping("/pay")
    public void payOrderNotify() throws IOException {
        try {
            // 1. 将HTTP请求转换为通知响应模型
            PayOrderNotifyResModel notifyModel = JeepayNotifyKit.convertNotifyResModel(request);

            String mchNo = notifyModel.getMchNo();
            String appId = notifyModel.getAppId();
            String mchOrderNo = notifyModel.getMchOrderNo();

            // 2. 获取应用密钥
            String appSecret = getAppSecret(mchNo, appId);

            // 3. 验签（关键步骤，防止伪造通知）
            if (!notifyModel.checkSign(appSecret)) {
                response.getWriter().print("sign fail");
                return;
            }

            // 4. 幂等处理：检查订单是否已处理
            if (processedOrders.putIfAbsent(mchOrderNo, true) != null) {
                // 订单已处理过，直接返回成功
                response.getWriter().print("SUCCESS");
                return;
            }

            // 5. 业务处理
            String state = notifyModel.getState();      // 2-支付成功 3-支付失败
            String errCode = notifyModel.getErrCode();
            String errMsg = notifyModel.getErrMsg();

            if ("2".equals(state)) {
                // 支付成功 -> 更新商户侧订单状态、发货等
                handlePaySuccess(notifyModel);
            } else {
                // 支付失败
                handlePayFail(notifyModel);
            }

            // 6. 响应 "SUCCESS" 告知计全付已成功接收（否则会重复通知）
            response.getWriter().print("SUCCESS");

        } catch (Exception e) {
            // 处理异常，返回非SUCCESS让计全付重试
            response.getWriter().print("FAIL");
        }
    }

    // ==================== 退款结果通知 ====================

    @PostMapping("/refund")
    public void refundOrderNotify() throws IOException {
        try {
            // 退款通知模型同样通过 JeepayNotifyKit 转换
            PayOrderNotifyResModel notifyModel = JeepayNotifyKit.convertNotifyResModel(request);

            String appSecret = getAppSecret(notifyModel.getMchNo(), notifyModel.getAppId());

            // 验签
            if (!notifyModel.checkSign(appSecret)) {
                response.getWriter().print("sign fail");
                return;
            }

            // 幂等处理
            String refundKey = "refund:" + notifyModel.getMchOrderNo();
            if (processedOrders.putIfAbsent(refundKey, true) != null) {
                response.getWriter().print("SUCCESS");
                return;
            }

            // 业务处理
            String state = notifyModel.getState();
            if ("2".equals(state)) {
                // 退款成功
                handleRefundSuccess(notifyModel);
            } else if ("3".equals(state)) {
                // 退款失败
                handleRefundFail(notifyModel);
            }

            response.getWriter().print("SUCCESS");

        } catch (Exception e) {
            response.getWriter().print("FAIL");
        }
    }

    // ==================== 转账结果通知 ====================

    @PostMapping("/transfer")
    public void transferOrderNotify() throws IOException {
        try {
            PayOrderNotifyResModel notifyModel = JeepayNotifyKit.convertNotifyResModel(request);

            String appSecret = getAppSecret(notifyModel.getMchNo(), notifyModel.getAppId());

            // 验签
            if (!notifyModel.checkSign(appSecret)) {
                response.getWriter().print("sign fail");
                return;
            }

            // 幂等处理
            String transferKey = "transfer:" + notifyModel.getMchOrderNo();
            if (processedOrders.putIfAbsent(transferKey, true) != null) {
                response.getWriter().print("SUCCESS");
                return;
            }

            // 业务处理
            String state = notifyModel.getState();
            if ("2".equals(state)) {
                // 转账成功
                handleTransferSuccess(notifyModel);
            } else if ("3".equals(state)) {
                // 转账失败
                handleTransferFail(notifyModel);
            }

            response.getWriter().print("SUCCESS");

        } catch (Exception e) {
            response.getWriter().print("FAIL");
        }
    }

    // ==================== 业务处理方法 ====================

    private void handlePaySuccess(PayOrderNotifyResModel notifyModel) {
        // 1. 根据 mchOrderNo 查询本地订单
        // 2. 校验金额是否一致
        // 3. 更新订单状态为"已支付"
        // 4. 触发后续业务（发货、开通会员等）
        System.out.println("支付成功: " + notifyModel.getMchOrderNo()
                + ", 金额: " + notifyModel.getAmount() + "分");
    }

    private void handlePayFail(PayOrderNotifyResModel notifyModel) {
        System.out.println("支付失败: " + notifyModel.getMchOrderNo()
                + ", 原因: " + notifyModel.getErrMsg());
    }

    private void handleRefundSuccess(PayOrderNotifyResModel notifyModel) {
        // 更新退款状态、恢复库存等
        System.out.println("退款成功: " + notifyModel.getMchOrderNo());
    }

    private void handleRefundFail(PayOrderNotifyResModel notifyModel) {
        System.out.println("退款失败: " + notifyModel.getMchOrderNo()
                + ", 原因: " + notifyModel.getErrMsg());
    }

    private void handleTransferSuccess(PayOrderNotifyResModel notifyModel) {
        System.out.println("转账成功: " + notifyModel.getMchOrderNo());
    }

    private void handleTransferFail(PayOrderNotifyResModel notifyModel) {
        System.out.println("转账失败: " + notifyModel.getMchOrderNo()
                + ", 原因: " + notifyModel.getErrMsg());
    }
}
```

## 关键注意事项

1. **验签必须执行**：所有通知必须通过 `checkSign(appSecret)` 验签后才可信任，防止伪造通知。
2. **必须做幂等处理**：计全付可能对同一笔订单发送多次通知，商户需确保重复通知不会导致重复处理。
3. **响应要求**：处理成功后返回 `SUCCESS` 字符串（HTTP 200），其他响应计全付会按策略重试。
4. **重试机制**：计全付通常会在通知失败后间隔重试（如1m/5m/10m/30m/1h/2h...），商户应能处理延迟到达的通知。
5. **金额校验**：建议在业务处理中校验通知金额与原始订单金额是否一致。
