# 转账扩展

转账扩展接口包含：转账余额查询、转账凭证申请、转账凭证查询、资金转账支付（充值）。

API路径：
- 转账余额查询：`api/transfer/balance/query`
- 转账凭证申请：`api/transfer/certificate/apply`
- 转账凭证查询：`api/transfer/certificate/query`
- 资金转账支付：`api/fund/trans/pay`

在线文档：
- 转账余额查询：https://doc.jeequan.com/#/integrate/jqf/api/51
- 转账凭证申请：https://doc.jeequan.com/#/integrate/jqf/api/52
- 转账凭证查询：https://doc.jeequan.com/#/integrate/jqf/api/53
- 资金转账支付：https://doc.jeequan.com/#/integrate/jqf/api/54

## 1. 转账余额查询

```java
import com.jeequan.jeepay.JeepayClient;
import com.jeequan.jeepay.exception.JeepayException;
import com.jeequan.jeepay.model.TransferBalanceQueryReqModel;
import com.jeequan.jeepay.model.TransferBalanceQueryResModel;
import com.jeequan.jeepay.request.TransferBalanceQueryRequest;
import com.jeequan.jeepay.response.TransferBalanceQueryResponse;

public class TransferBalanceQueryExample {

    public static void main(String[] args) {

        String apiBase = "https://pay.jeepay.cn";
        String apiKey  = "yourAppSecret";
        JeepayClient client = new JeepayClient(apiBase, apiKey);

        TransferBalanceQueryReqModel model = new TransferBalanceQueryReqModel();
        model.setMchNo("M1679428700001");           // 商户号
        model.setAppId("66372b9c09992a00081e52ae"); // 应用ID
        model.setIfCode("aliaqfpay");               // 支付接口代码

        TransferBalanceQueryRequest request = new TransferBalanceQueryRequest();
        request.setBizModel(model);

        try {
            TransferBalanceQueryResponse response = client.execute(request);
            if (response.getCode() != 0) {
                System.err.println("查询失败: " + response.getMsg());
                return;
            }
            if (!response.isSuccess(apiKey)) {
                System.err.println("验签失败");
                return;
            }
            TransferBalanceQueryResModel resModel = response.get();
            System.out.println("可用余额: " + resModel.getBalanceAmount() + " 分");
        } catch (JeepayException e) {
            System.err.println("请求异常: " + e.getMessage());
        }
    }
}
```

### 成功响应示例

```json
{
    "code": 0,
    "msg": "SUCCESS",
    "sign": "A1B2C3D4E5F6...",
    "data": {
        "balanceAmount": 100000
    }
}
```

## 4. 资金转账支付（充值）

```java
import com.jeequan.jeepay.JeepayClient;
import com.jeequan.jeepay.exception.JeepayException;
import com.jeequan.jeepay.model.TransferApiServiceFundTransPayReqModel;
import com.jeequan.jeepay.model.TransferApiServiceFundTransPayResModel;
import com.jeequan.jeepay.request.TransferApiServiceFundTransPayRequest;
import com.jeequan.jeepay.response.TransferApiServiceFundTransPayResponse;

public class TransferFundTransPayExample {

    public static void main(String[] args) {

        String apiBase = "https://pay.jeepay.cn";
        String apiKey  = "yourAppSecret";
        JeepayClient client = new JeepayClient(apiBase, apiKey);

        TransferApiServiceFundTransPayReqModel model = new TransferApiServiceFundTransPayReqModel();
        model.setMchNo("M1679428700001");           // 商户号
        model.setAppId("66372b9c09992a00081e52ae"); // 应用ID
        model.setIfCode("aliaqfpay");               // 支付接口代码
        model.setAmount(1L);                        // 充值金额，单位：分
        model.setRechargeType((byte) 0);            // 充值类型：0-线上充值 1-线下充值

        TransferApiServiceFundTransPayRequest request = new TransferApiServiceFundTransPayRequest();
        request.setBizModel(model);

        try {
            TransferApiServiceFundTransPayResponse response = client.execute(request);
            if (response.getCode() != 0) {
                System.err.println("充值失败: " + response.getMsg());
                return;
            }
            TransferApiServiceFundTransPayResModel resModel = response.get();
            // 线上充值时返回表单数据
            System.out.println("充值类型: " + resModel.getRechargeType());
            if (resModel.getRechargeType() == 0) {
                System.out.println("表单内容: " + resModel.getFormContent());
            } else {
                // 线下充值时返回银行卡信息
                System.out.println("卡号: " + resModel.getCardNo());
                System.out.println("开户行: " + resModel.getCardBank());
            }
        } catch (JeepayException e) {
            System.err.println("请求异常: " + e.getMessage());
        }
    }
}
```

### 成功响应示例

```json
{
    "code": 0,
    "msg": "SUCCESS",
    "sign": "A1B2C3D4E5F6...",
    "data": {
        "formContent": "<form>...</form>",
        "rechargeType": 0
    }
}
```
