# 分账扩展

分账扩展接口包含：绑定/查询分账用户、查询/完结分账、余额分账执行/查询、渠道余额查询/提现、提现记录查询、结算更新。

API路径：
- 绑定分账用户：`api/division/receiver/bind`
- 查询分账绑定：`api/division/receiver/bindQuery`
- 查询分账：`api/division/query`
- 完成分账：`api/division/finish`
- 余额分账执行：`api/division/balance/exec`
- 余额分账查询：`api/division/balance/query`
- 渠道余额查询：`api/division/receiver/channelBalanceQuery`
- 渠道余额提现：`api/division/receiver/channelBalanceCashout`
- 提现记录查询：`api/division/receiver/cashoutRecordQuery`
- 结算更新：`api/division/receiver/settle/update`

## 1. 绑定分账用户

```java
import com.jeequan.jeepay.JeepayClient;
import com.jeequan.jeepay.exception.JeepayException;
import com.jeequan.jeepay.model.DivisionReceiverBindReqModel;
import com.jeequan.jeepay.model.DivisionReceiverBindResModel;
import com.jeequan.jeepay.request.DivisionReceiverBindRequest;
import com.jeequan.jeepay.response.DivisionReceiverBindResponse;

public class DivisionReceiverBindExample {

    public static void main(String[] args) {

        String apiBase = "https://pay.jeepay.cn";
        String apiKey  = "yourAppSecret";
        JeepayClient client = new JeepayClient(apiBase, apiKey);

        DivisionReceiverBindReqModel model = new DivisionReceiverBindReqModel();
        model.setMchNo("M1679428700001");           // 商户号
        model.setAppId("66372b9c09992a00081e52ae"); // 应用ID
        model.setIfCode("demomockpay");             // 接口代码
        model.setMchReceiverId("23472389482349");   // 商户分账用户ID
        model.setReceiverAlias("15521254124");      // 接收者账号别名
        model.setAccType((byte) 0);                 // 账号类型：0-个人(对私) 1-商户(对公)
        model.setAccNo("15521254124");              // 分账接收账号
        model.setRelationType("PARTNER");           // 分账关系类型
        model.setDivisionProfit("0.3");             // 默认分账比例（0.3 = 30%）

        DivisionReceiverBindRequest request = new DivisionReceiverBindRequest();
        request.setBizModel(model);

        try {
            DivisionReceiverBindResponse response = client.execute(request);
            if (response.getCode() != 0) {
                System.err.println("绑定失败: " + response.getMsg());
                return;
            }
            DivisionReceiverBindResModel resModel = response.get();
            System.out.println("接收者ID: " + resModel.getReceiverId());
            System.out.println("绑定状态: " + resModel.getBindState()); // 1-绑定成功 0-绑定异常
        } catch (JeepayException e) {
            System.err.println("请求异常: " + e.getMessage());
        }
    }
}
```

```java
                System.err.println("更新失败: " + response.getMsg());
                return;
            }
            System.out.println("结算信息更新成功");
        } catch (JeepayException e) {
            System.err.println("请求异常: " + e.getMessage());
        }
    }
}
```
