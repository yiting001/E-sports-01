# 退款

API路径：`api/refund/refundOrder`

在线文档：https://doc.jeequan.com/#/integrate/jqf/api/48

## SDK调用示例（Python）

```python
# -*- coding: utf-8 -*-
"""
退款示例
对已支付成功的订单发起退款。
"""

from jeepay import AppConfig, Pay

# ============================================================
# 1. 初始化 SDK 配置
# ============================================================
AppConfig.set_mch_no("M1671695486")
AppConfig.set_app_id("607cc0a0ee11e11e7c80")
AppConfig.set_api_key("YourApiKey1234567890")

# ============================================================
# 2. 发起退款
# ============================================================
result = Pay.refund(
    # 订单标识（mchOrderNo / payOrderId 二选一）
    mchOrderNo="M20260521143000",       # 商户订单号
    # payOrderId="P202605211430000001", # 支付订单号

    # 退款参数
    mchRefundNo="R20260521150000",      # 商户退款单号（需保证唯一）
    refundAmount=100,                    # 退款金额，单位：分（100 = 1元）
    # 退款金额不能大于订单实际支付金额
    # 支持部分退款（退款金额小于支付金额）

    # 可选参数
    currency="cny",                      # 币种
    refundReason="用户申请退款",          # 退款原因
    notifyUrl="https://your-domain.com/api/notify/refund",  # 退款异步通知地址
)

# ============================================================
# 3. 处理返回结果
# ============================================================
if result.get("code") == 0:
    print("退款申请成功！")
    refund_data = result.get("data", {})
    print(f"退款订单号: {refund_data.get('refundOrderId')}")
    print(f"商户退款单号: {refund_data.get('mchRefundNo')}")
    print(f"退款状态: {refund_data.get('state')}")
    # state 状态说明：
    #   0 - 退款生成
    #   1 - 退款中
    #   2 - 退款成功
    #   3 - 退款失败
    print(f"退款金额: {refund_data.get('refundAmount')} 分")
else:
    print(f"退款申请失败！code={result.get('code')}, msg={result.get('msg')}")
```
