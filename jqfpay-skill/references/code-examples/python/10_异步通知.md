异步通知处理示例（Flask）

重要：
1. 必须验签后再处理业务逻辑
2. 处理成功后必须返回固定格式的响应
3. 同一通知可能会重复发送，需做幂等处理
"""

# 验签工具函数
# ============================================================
def verify_sign(params):
    """
    验证异步通知签名

    计全付异步通知签名规则：
    1. 获取所有非 sign 的参数
    2. 按 ASCII 字典序排列参数名
    3. 拼接为 key1=value1&key2=value2 格式
    4. 拼接 apiKey：key1=value1&key2=value2&key=apiKey
    5. MD5 签名方式：对拼接串做 MD5 得到 sign
    6. RSA2 签名方式：使用平台公钥验签
    """
    import hashlib

    sign = params.get("sign", "")
    sign_type = params.get("signType", "MD5")

    # 取所有非 sign 和 signType 的参数
    filtered = {k: v for k, v in params.items()
                if k not in ("sign", "signType") and v is not None and v != ""}

    # 按 ASCII 字典序排列
    sorted_keys = sorted(filtered.keys())

    # 拼接参数
    sign_str = "&".join(f"{k}={filtered[k]}" for k in sorted_keys)

    if sign_type == "MD5":
        # MD5 签名：拼接串 + &key=apiKey
        sign_str += f"&key={AppConfig.get_api_key()}"
        calculated = hashlib.md5(sign_str.encode("utf-8")).hexdigest().upper()
        return calculated == sign.upper()

    elif sign_type == "RSA2":
        # RSA2 签名：使用平台公钥验签
        # 需要加载平台公钥证书
        from jeepay.sign_utils import verify_rsa2
        return verify_rsa2(sign_str, sign)

    return False


# ============================================================
# 支付结果通知
# ============================================================
@app.route("/api/notify/pay", methods=["POST"])
def pay_notify():
    """
    支付结果异步通知
    请求方式：POST
    参数格式：application/x-www-form-urlencoded 或 JSON
    """
    # 获取通知参数
    if request.content_type and "json" in request.content_type:
        params = request.get_json(force=True)
    else:
        params = request.form.to_dict()

    print(f"收到支付通知: {params}")

    # 1. 验签
    if not verify_sign(params):
        print("验签失败！")
        return jsonify({"code": "FAIL", "msg": "验签失败"})

    # 2. 处理业务逻辑
    state = params.get("state")
    pay_order_id = params.get("payOrderId")
    mch_order_no = params.get("mchOrderNo")
    order_amount = params.get("orderAmount")
    success_time = params.get("successTime")
    channel_order_no = params.get("channelOrderNo")

    try:
        if state == "2":
            # 支付成功
            print(f"支付成功！订单号: {mch_order_no}, 金额: {order_amount}分")

            # TODO: 业务处理（幂等）
            # - 检查订单是否已处理（防止重复通知）
            # - 更新订单状态
            # - 发货等业务逻辑
            pass
        else:
            # 支付失败或其他状态
            print(f"支付状态: {state}")
            # TODO: 更新订单状态

        # 3. 返回成功响应（固定格式，告诉平台已接收）
        return jsonify({"code": "SUCCESS", "msg": "成功"})

    except Exception as e:
        print(f"处理异常: {e}")
        # 返回失败，平台会重试通知
        return jsonify({"code": "FAIL", "msg": "处理异常"})

## 成功响应格式

通知处理成功后，返回以下固定格式（计全付收到后不再重发通知）：

```json
{
    "code": "SUCCESS",
    "msg": "成功"
}
```

## 失败响应格式

通知处理失败时返回，计全付会按策略重发通知（最多重试5次，间隔递增）：

```json
{
    "code": "FAIL",
    "msg": "处理异常"
}
```

## 注意事项

1. **验签必须**：始终先验证签名再处理业务逻辑，防止伪造通知
2. **幂等处理**：同一通知可能重复发送，通过订单号判断是否已处理
3. **返回格式**：处理成功必须返回 `{"code": "SUCCESS"}`，否则平台会持续重试
4. **超时设置**：通知接口应在 10 秒内返回响应，超时视为失败
5. **签名方式**：MD5 和 RSA2 的验签方式不同，需根据 signType 区分处理
6. **HTTPS**：生产环境通知地址必须使用 HTTPS
