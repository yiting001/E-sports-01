# 关闭订单

API路径：`api/pay/close`

在线文档：https://doc.jeequan.com/#/integrate/jqf/api/41

## SDK调用示例（Python）

```python
# -*- coding: utf-8 -*-
"""
关闭订单示例
关闭未支付的订单，已支付成功的订单无法关闭。
"""

from jeepay import AppConfig, Pay

# ============================================================
# 1. 初始化 SDK 配置
# ============================================================
AppConfig.set_mch_no("M1671695486")
AppConfig.set_app_id("607cc0a0ee11e11e7c80")
AppConfig.set_api_key("YourApiKey1234567890")

# ============================================================
# 2. 通过商户订单号关闭
# ============================================================
result = Pay.pay_close(
    mchOrderNo="M20260521143000",  # 商户订单号（与 payOrderId 二选一）
)

# ============================================================
# 3. 通过支付订单号关闭
# ============================================================
# result = Pay.pay_close(
#     payOrderId="P202605211430000001",  # 支付订单号（与 mchOrderNo 二选一）
# )

# ============================================================
# 4. 处理返回结果
# ============================================================
if result.get("code") == 0:
    print("关单成功！")
    order_data = result.get("data", {})
    print(f"支付订单号: {order_data.get('payOrderId')}")
    print(f"商户订单号: {order_data.get('mchOrderNo')}")
    print(f"订单状态: {order_data.get('state')}")  # 关闭成功后 state 应为 6（已关闭）
else:
    print(f"关单失败！code={result.get('code')}, msg={result.get('msg')}")
```

## 成功响应示例

```json
{
    "code": 0,
    "msg": "SUCCESS",
    "data": {
        "payOrderId": "P202605211430000001",
        "mchOrderNo": "M20260521143000",
        "state": 6
    }
}
```
