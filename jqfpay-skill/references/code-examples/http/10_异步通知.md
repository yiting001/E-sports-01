## 通知处理要求

### 商户响应格式

处理成功时返回纯文本：

```
SUCCESS
```

处理失败时返回：

```
FAIL
```

### 通知重试机制

- 计全付在未收到 `SUCCESS` 响应时会进行重试
- 重试间隔：15s, 30s, 3m, 10m, 20m, 30m, 30m, 30m, 60m, 3h, 3h, 3h, 6h, 6h
- 总计最多重试 14 次
- 商户需做幂等处理，避免重复更新

### 验签步骤

```
1. 从通知 JSON 中取出 sign 字段值
2. 移除 sign 字段
3. 过滤空值参数
4. 按 key 的 ASCII 字典序排序（不区分大小写）
5. 拼接 key1=value1&key2=value2... 格式
6. 末尾追加 &key=apiKey
7. MD5 哈希后转大写
8. 比对计算结果与 sign 是否一致
```

### 通知字段说明

| 字段 | 支付通知 | 退款通知 | 转账通知 |
|------|---------|---------|---------|
| state | 2-成功 3-失败 | 2-成功 3-失败 | 2-成功 3-失败 4-退回 |
| amount | 支付金额（分） | - | 转账金额（分） |
| refundAmount | - | 退款金额（分） | - |
| channelOrderNo | 上游渠道订单号 | 上游渠道退款单号 | 上游渠道转账单号 |
| successTime | 支付成功时间（ms） | 退款成功时间（ms） | 转账成功时间（ms） |
