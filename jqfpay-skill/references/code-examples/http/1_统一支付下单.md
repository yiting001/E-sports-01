### 不同支付方式的 channelExtra 参数

```http
// WX_LITE 微信小程序
"wayCode": "WX_LITE",
"channelExtra": "{\"openid\":\"o6BcIwvSiRpfS8e_UyfQNrYuk2LI\"}"

// QR_CASHIER 聚合扫码（用户扫商家）
"wayCode": "QR_CASHIER",
"channelExtra": "{\"payDataType\":\"codeImgUrl\",\"entryPageType\":\"h5\"}"

// AUTO_BAR 聚合条码（商家扫用户）
"wayCode": "AUTO_BAR",
"channelExtra": "{\"authCode\":\"13920933111042\"}"

// WX_NATIVE 微信扫码
"wayCode": "WX_NATIVE",
"channelExtra": "{\"payDataType\":\"codeUrl\"}"

// ALI_APP 支付宝APP
"wayCode": "ALI_APP",
"channelExtra": "{}"

// WEB_CASHIER WEB收银台
"wayCode": "WEB_CASHIER",

// TG_PAY 托管支付
"wayCode": "TG_PAY",
"channelExtra": "{\"userPayType\":\"wx\",\"invokeType\":\"app2lite\"}"
```

## 成功响应示例

```json
{
  "code": 0,
  "msg": "SUCCESS",
  "data": {
    "payOrderId": "P2026052114300000001",
    "mchOrderNo": "ORDER202605211430001234",
    "orderState": 1,
    "payDataType": "wxapp",
    "payData": "{\"appId\":\"wx1234567890\",\"timeStamp\":\"1684656000\",\"nonceStr\":\"abc123\",\"package\":\"prepay_id=wx201234\",\"signType\":\"RSA\",\"paySign\":\"sign123\"}"
  },
  "sign": "A1B2C3D4E5F6A7B8C9D0E1F2A3B4C5D6"
}
```

### payDataType 与 payData 含义

| payDataType | 说明 | 处理方式 |
|-------------|------|----------|
| wxapp | 微信支付参数 | 调用微信JS-SDK/小程序 wx.requestPayment |
| aliapp | 支付宝APP参数 | 调用支付宝SDK |
| ysfapp | 云闪付APP参数 | 调用云闪付SDK |
| codeUrl | 二维码链接 | 前端生成二维码展示 |
| codeImgUrl | 二维码图片地址 | 前端直接展示图片 |
| payurl | 跳转链接 | 重定向到该URL |
| form | 自动提交表单 | 输出到页面自动提交 |
| none | 无支付参数 | 条码支付直接完成，无需额外操作 |
