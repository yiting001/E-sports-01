# 钱包

API路径：

| 接口 | API路径 |
|------|---------|
| 创建钱包 | `api/wallet/user` |
| 绑定银行卡 | `api/wallet/bankcard/bind` |
| 查询钱包用户 | `api/wallet/user/query` |
| 钱包变动明细 | `api/wallet/user/changeDetails` |
| 钱包提现 | `api/wallet/cashout` |
| 查询钱包提现 | `api/wallet/cashout/query` |
| 钱包转账 | `api/wallet/transfer` |
| 查询钱包转账 | `api/wallet/transfer/query` |

## HTTP 示例

### 1. 创建钱包

```http
POST /api/wallet/user HTTP/1.1
Host: your-jqf-domain.com
Content-Type: application/json
Accept: application/json

{

  "appId": "6064c5c8f3e4a24e5b8e1a3c",
  "mchOrderNo": "W202605261530001234",
  "ifCode": "hnawalletpay",
  "idcardNo": "412928194606080028",
  "idcardName": "张三",

  "bankName": "中国建设银行",
```

## 成功响应示例

### 创建钱包

```json
{
  "code": 0,
  "msg": "SUCCESS",
  "data": {
    "walletId": "2024102414555816",
    "channelState": 1,
    "errCode": "",
    "errMsg": ""
  },
  "sign": "A7B8C9D0E1F2A3B4C5D6E7F8A9B0C1D2"
}
```

**channelState 状态说明**

| channelState | 含义 |
|-------------|------|
| 0 | 未开户 |
| 1 | 开户成功 |
| 2 | 待审核 |
| 3 | 审核拒绝 |
| 4 | 待激活 |
| 5 | 开户失败 |
| 6 | 已注销 |
