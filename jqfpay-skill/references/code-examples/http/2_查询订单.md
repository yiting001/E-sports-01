# 查询订单

API路径：`api/pay/query`

在线文档：https://doc.jeequan.com/#/integrate/jqf/api/40

## HTTP 示例

```http
POST /api/pay/query HTTP/1.1
Host: your-jqf-domain.com
Content-Type: application/json
Accept: application/json

{
  "mchNo": "M1640000001",
  "appId": "6064c5c8f3e4a24e5b8e1a3c",
  "mchOrderNo": "ORDER202605211430001234",
  "version": "1.0",
  "signType": "MD5",
  "reqTime": "20260521143100",
  "sign": "B2C3D4E5F6A7B8C9D0E1F2A3B4C5D6E7"
}
```

### 使用支付系统订单号查询

```http
POST /api/pay/query HTTP/1.1
Host: your-jqf-domain.com
Content-Type: application/json
Accept: application/json

{

### 订单状态说明

| state | 含义 |
|-------|------|
| 0 | 订单生成 |
| 1 | 支付中 |
| 2 | 支付成功 |
| 3 | 支付失败 |
| 4 | 已撤销 |
| 5 | 已退款 |
| 6 | 退款中 |

## 失败响应示例

{
  "code": 2000,
  "msg": "订单不存在",
  "data": null,
  "sign": null
}
```
