# 退款

API路径：`api/refund/refundOrder`

在线文档：https://doc.jeequan.com/#/integrate/jqf/api/48

## HTTP 示例

```http
POST /api/refund/refundOrder HTTP/1.1
Host: your-jqf-domain.com
Content-Type: application/json
Accept: application/json

{
  "mchNo": "M1640000001",
  "appId": "6064c5c8f3e4a24e5b8e1a3c",
  "mchOrderNo": "ORDER202605211430001234",
  "mchRefundNo": "REF202605211500001234",
  "refundAmount": 1,
  "currency": "CNY",
  "refundReason": "用户申请退款",
  "clientIp": "192.168.1.100",
  "notifyUrl": "https://your-domain.com/notify/refund",
  "version": "1.0",
  "signType": "MD5",
  "reqTime": "20260521150000",
  "sign": "D4E5F6A7B8C9D0E1F2A3B4C5D6E7F8A9"
}
```

### 退款状态说明

| state | 含义 |
|-------|------|
| 0 | 退款生成 |
| 1 | 退款中 |
| 2 | 退款成功 |
| 3 | 退款失败 |

## 失败响应示例

```json
{
  "code": 2000,
  "msg": "退款金额超出订单可退余额",
  "data": null,
  "sign": null
}
```
