# 进件

API路径：
- 上传文件：`api/mchApplyment/uploadFile`
- 商户进件：`api/mchApplyment/income`
- 查询进件：`api/mchApplyment/income/query`
- 签约信息：`api/mchApplyment/signInfo`

在线文档：
- 上传文件：https://doc.jeequan.com/#/integrate/jqf/api/344
- 商户进件：https://doc.jeequan.com/#/integrate/jqf/api/343

## 成功响应示例

### 上传文件成功

```json
{
  "code": 0,
  "msg": "SUCCESS",
  "data": {
    "fileId": "FILE2026052116100000001",
    "fileName": "id_card_front.jpg"
  },
  "sign": "B4C5D6E7F8A9B0C1D2E3F4A5B6C7D8E9"
}
```

### 提交进件成功

```json
{
  "code": 0,
  "msg": "SUCCESS",
  "data": {
    "applymentId": "AP2026052116150000001",
    "state": 0,
    "msg": "已提交审核"
  },
  "sign": "C5D6E7F8A9B0C1D2E3F4A5B6C7D8E9F0"
}
```

### 查询进件成功

```json
{
  "code": 0,
  "msg": "SUCCESS",
  "data": {
    "applymentId": "AP2026052116150000001",
    "mchNo": "M1640000001",
    "state": 3,
    "stateMsg": "审核通过，待签约",
    "signUrl": "https://pay.weixin.qq.com/sign/xxx"
  },
  "sign": "D6E7F8A9B0C1D2E3F4A5B6C7D8E9F0A1"
}
```

### 进件状态说明

| state | 含义 |
|-------|------|
| 0 | 审核中 |
| 1 | 审核通过 |
| 2 | 审核驳回 |
| 3 | 待签约 |
