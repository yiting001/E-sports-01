# 查询退款

API路径：`api/refund/query`

在线文档：https://doc.jeequan.com/#/integrate/jqf/api/49

## HTTP 示例

### 通过商户退款单号查询

```http
POST /api/refund/query HTTP/1.1
Host: your-jqf-domain.com
Content-Type: application/json
Accept: application/json

{
  "mchNo": "M1640000001",
  "appId": "6064c5c8f3e4a24e5b8e1a3c",
  "mchRefundNo": "REF202605211500001234",
  "version": "1.0",
  "signType": "MD5",
  "reqTime": "20260521150100",
  "sign": "A1B2C3D4E5F6A7B8C9D0E1F2A3B4C5D6"
}
```

### 通过退款系统订单号查询

```http
POST /api/refund/query HTTP/1.1
Host: your-jqf-domain.com
Content-Type: application/json
Accept: application/json

{
  "mchNo": "M1640000001",
  "appId": "6064c5c8f3e4a24e5b8e1a3c",
  "refundOrderId": "RF2026052115000000001",
  "version": "1.0",
  "signType": "MD5",
  "reqTime": "20260521150100",
  "sign": "B2C3D4E5F6A7B8C9D0E1F2A3B4C5D6E7"
}
```
