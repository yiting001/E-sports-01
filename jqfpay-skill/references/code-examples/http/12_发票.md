# 发票

API路径：

- 开票：`api/invoice/open`
- 查询发票：`api/invoice/query`
- 电子发票URL：`api/invoice/elecUrl`

在线文档：https://doc.jeequan.com/#/integrate/jqf/api/74

## 1. 开票

```http
POST /api/invoice/open HTTP/1.1
Host: your-jqf-domain.com
Content-Type: application/json
Accept: application/json

{
  "mchNo": "M1640000001",
  "appId": "6064c5c8f3e4a24e5b8e1a3c",
  "mchOrderNo": "FP202605261530001234",
  "invoiceWay": 2,
  "amount": 100,
  "clientIp": "127.0.0.1",
  "buyerInfo": "{\"buyerName\":\"测试公司\",\"taxNo\":\"91110108MA01XXXXXX\",\"pushPhone\":\"13800138000\"}",
  "notifyUrl": "https://your-domain.com/notify/invoice",
  "version": "1.0",
  "signType": "MD5",
  "reqTime": "20260526153000",
  "sign": "A1B2C3D4E5F6A7B8C9D0E1F2A3B4C5D6"
}
```

### curl 示例

```bash

  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -d '{
    "mchNo": "M1640000001",
    "appId": "6064c5c8f3e4a24e5b8e1a3c",
    "mchOrderNo": "FP202605261530001234",
    "invoiceWay": 2,
    "amount": 100,
    "clientIp": "127.0.0.1",
    "buyerInfo": "{\"buyerName\":\"测试公司\",\"taxNo\":\"91110108MA01XXXXXX\",\"pushPhone\":\"13800138000\"}",
    "notifyUrl": "https://your-domain.com/notify/invoice",
    "version": "1.0",
    "signType": "MD5",
    "reqTime": "20260526153000",
    "sign": "A1B2C3D4E5F6A7B8C9D0E1F2A3B4C5D6"
  }'
```

### 请求参数说明

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| mchNo | String | 是 | 商户号 |
| appId | String | 是 | 应用ID |
| mchOrderNo | String | 是 | 商户开票单号（保证唯一） |
| invoiceWay | Byte | 是 | 开票方式: 2-获取开票链接 |
| amount | Long | 是 | 含税开票金额，单位：分 |
| clientIp | String | 是 | 客户端IP地址 |
| buyerInfo | String | 是 | 购方信息，JSON字符串 |
| notifyUrl | String | 否 | 异步通知地址 |
| expiredDay | Integer | 否 | 开票链接有效期（天） |
| sellerInfo | String | 否 | 销方信息 |
| goodsList | String | 否 | 商品信息 |
| channelExtra | String | 否 | 特定渠道额外参数 |
| remark | String | 否 | 备注 |

### 购方信息（buyerInfo）字段

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| buyerName | String | 是 | 购方名称 |
| taxNo | String | 否 | 购方税号 |
| address | String | 否 | 购方地址 |
| telphone | String | 否 | 购方固定电话 |
| bankName | String | 否 | 开户行 |
| bankAccount | String | 否 | 开户账号 |
| pushPhone | String | 否 | 交付手机 |
| pushEmail | String | 否 | 交付邮箱 |

### 开票状态说明

| state | 含义 |
|-------|------|
| 0 | 订单生成 |
| 1 | 开票中 |
| 2 | 开票成功 |
| 3 | 开票失败 |
| 4 | 开票任务关闭 |
| 5 | 已冲红 |
| 6 | 已作废 |
