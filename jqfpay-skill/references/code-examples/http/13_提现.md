# 提现

API路径：

- 提现余额查询：`api/cashout/balance/query`
- 创建提现订单：`api/cashout/order/create`
- 查询提现订单：`api/cashout/order/query`

在线文档：https://doc.jeequan.com/#/integrate/jqf/api/77

## 1. 提现余额查询

```http
POST /api/cashout/balance/query HTTP/1.1
Host: your-jqf-domain.com
Content-Type: application/json
Accept: application/json

{
  "mchNo": "M1640000001",
  "appId": "6064c5c8f3e4a24e5b8e1a3c",
  "ifCode": "dgpay",
  "version": "1.0",
  "signType": "MD5",
  "reqTime": "20260526153000",
  "sign": "A1B2C3D4E5F6A7B8C9D0E1F2A3B4C5D6"
}
```

### curl 示例

```bash
curl -X POST https://your-jqf-domain.com/api/cashout/balance/query \
  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -d '{
    "mchNo": "M1640000001",
    "appId": "6064c5c8f3e4a24e5b8e1a3c",
    "ifCode": "dgpay",
    "version": "1.0",
    "signType": "MD5",
    "reqTime": "20260526153000",
    "sign": "A1B2C3D4E5F6A7B8C9D0E1F2A3B4C5D6"
  }'
```

## 2. 创建提现订单

```http
POST /api/cashout/order/create HTTP/1.1
Host: your-jqf-domain.com
Content-Type: application/json
Accept: application/json

{
  "mchNo": "M1640000001",
  "appId": "6064c5c8f3e4a24e5b8e1a3c",
  "mchOrderNo": "CO202605261530001234",
  "amount": 100,
  "ifCode": "dgpay",
  "notifyUrl": "https://your-domain.com/notify/cashout",
  "channelExtra": "",
  "remark": "测试提现备注",
  "version": "1.0",
  "signType": "MD5",
  "reqTime": "20260526153000",
  "sign": "B2C3D4E5F6A7B8C9D0E1F2A3B4C5D6E7"
}
```

### curl 示例

```bash
curl -X POST https://your-jqf-domain.com/api/cashout/order/create \
  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -d '{
    "mchNo": "M1640000001",
    "appId": "6064c5c8f3e4a24e5b8e1a3c",
    "mchOrderNo": "CO202605261530001234",
    "amount": 100,
    "ifCode": "dgpay",
    "notifyUrl": "https://your-domain.com/notify/cashout",
    "channelExtra": "",
    "remark": "测试提现备注",
    "version": "1.0",
    "signType": "MD5",
    "reqTime": "20260526153000",
    "sign": "B2C3D4E5F6A7B8C9D0E1F2A3B4C5D6E7"
  }'
```

### 请求参数说明

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| mchNo | String | 是 | 商户号 |
| appId | String | 是 | 应用ID |
| mchOrderNo | String | 是 | 商户提现单号（保证唯一） |
| amount | Long | 是 | 提现金额，单位：分 |
| ifCode | String | 是 | 支付接口代码 |
| notifyUrl | String | 否 | 异步通知地址 |
| channelExtra | String | 否 | 特定渠道额外参数 |
| remark | String | 否 | 备注 |
