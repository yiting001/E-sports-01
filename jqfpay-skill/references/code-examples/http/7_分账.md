# 分账

API路径：`api/division/exec`

在线文档：https://doc.jeequan.com/#/integrate/jqf/api/57

## HTTP 示例

### 使用系统自动分账组

```http
POST /api/division/exec HTTP/1.1
Host: your-jqf-domain.com
Content-Type: application/json
Accept: application/json

{
  "mchNo": "M1640000001",
  "appId": "6064c5c8f3e4a24e5b8e1a3c",
  "mchOrderNo": "ORDER202605211430001234",
  "useSysAutoDivisionReceivers": 1,
  "autoFinish": 1,
  "version": "1.0",
  "signType": "MD5",
  "reqTime": "20260521154500",
  "sign": "A1B2C3D4E5F6A7B8C9D0E1F2A3B4C5D6"
}
```

### 手动指定分账接收方（按账号维度）

```http
POST /api/division/exec HTTP/1.1
Host: your-jqf-domain.com
Content-Type: application/json
Accept: application/json

{
  "mchNo": "M1640000001",
  "appId": "6064c5c8f3e4a24e5b8e1a3c",
  "payOrderId": "P2026052114300000001",
  "useSysAutoDivisionReceivers": 0,
  "autoFinish": 1,
  "receivers": "[{\"receiverId\":800001,\"divisionProfit\":0.1},{\"receiverId\":800002,\"divisionProfit\":0.15}]",
  "version": "1.0",
  "signType": "MD5",
  "reqTime": "20260521154500",
  "sign": "B2C3D4E5F6A7B8C9D0E1F2A3B4C5D6E7"
}
```

### 手动指定分账接收方（按组维度）

```http
POST /api/division/exec HTTP/1.1
Host: your-jqf-domain.com
Content-Type: application/json
Accept: application/json

{
  "mchNo": "M1640000001",
  "appId": "6064c5c8f3e4a24e5b8e1a3c",
  "mchOrderNo": "ORDER202605211430001234",
  "useSysAutoDivisionReceivers": 0,
  "autoFinish": 0,
  "receivers": "[{\"receiverGroupId\":100001,\"divisionProfit\":0.2}]",
  "version": "1.0",
  "signType": "MD5",
  "reqTime": "20260521154500",
  "sign": "C3D4E5F6A7B8C9D0E1F2A3B4C5D6E7F8"
}
```

### 参数说明

| 参数 | 说明 |
|------|------|
| mchOrderNo | 商户订单号（与 payOrderId 二选一） |
| payOrderId | 支付系统订单号（与 mchOrderNo 二选一） |
| useSysAutoDivisionReceivers | 0-不使用系统自动分账组 1-使用 |
| autoFinish | 0-不解冻剩余资金 1-分账完成后自动解冻 |
| receivers | 分账接收方列表（JSON数组字符串） |
| templateId | 分账模板ID（可选） |

### receivers 格式说明

```json
// 按账号维度
[
  {
    "receiverId": 800001,
    "divisionProfit": 0.1
  }
]

// 按组维度
[
  {
    "receiverGroupId": 100001,
    "divisionProfit": 0.15
  }
]
```
