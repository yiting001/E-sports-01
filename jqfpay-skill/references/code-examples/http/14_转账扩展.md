# 转账扩展

转账扩展接口包含：转账余额查询、转账凭证申请、转账凭证查询、资金转账支付（充值）。

API路径：
- 转账余额查询：`api/transfer/balance/query`
- 转账凭证申请：`api/transfer/certificate/apply`
- 转账凭证查询：`api/transfer/certificate/query`
- 资金转账支付：`api/fund/trans/pay`

在线文档：
- 转账余额查询：https://doc.jeequan.com/#/integrate/jqf/api/51
- 转账凭证申请：https://doc.jeequan.com/#/integrate/jqf/api/52
- 转账凭证查询：https://doc.jeequan.com/#/integrate/jqf/api/53
- 资金转账支付：https://doc.jeequan.com/#/integrate/jqf/api/54

## 1. 转账余额查询

```http
POST /api/transfer/balance/query HTTP/1.1
Host: your-jqf-domain.com
Content-Type: application/json
Accept: application/json

{
  "mchNo": "M1640000001",
  "appId": "6064c5c8f3e4a24e5b8e1a3c",
  "ifCode": "aliaqfpay",
  "version": "1.0",
  "signType": "MD5",
  "reqTime": "20260521153000",
  "sign": "A1B2C3D4E5F6A7B8C9D0E1F2A3B4C5D6"
}
```

### 成功响应

```json
{
  "code": 0,
  "msg": "SUCCESS",
  "data": {
    "balanceAmount": 100000
  },
  "sign": "D4E5F6A7B8C9D0E1F2A3B4C5D6E7F8A9"
}
```

## 4. 资金转账支付（线上充值）

```http
POST /api/fund/trans/pay HTTP/1.1
Host: your-jqf-domain.com
Content-Type: application/json
Accept: application/json

{
  "mchNo": "M1640000001",
  "appId": "6064c5c8f3e4a24e5b8e1a3c",
  "ifCode": "aliaqfpay",
  "amount": 1,
  "rechargeType": 0,
  "version": "1.0",
  "signType": "MD5",
  "reqTime": "20260521153000",
  "sign": "D4E5F6A7B8C9D0E1F2A3B4C5D6E7F8A9"
}
```

### 成功响应（线上充值）

```json
{
  "code": 0,
  "msg": "SUCCESS",
  "data": {
    "formContent": "<form>...</form>",
    "rechargeType": 0
  },
  "sign": "A7B8C9D0E1F2A3B4C5D6E7F8A9B0C1D2"
}
```
