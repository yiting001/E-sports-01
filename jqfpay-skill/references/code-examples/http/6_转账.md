# 转账

API路径：`api/transferOrder`

在线文档：https://doc.jeequan.com/#/integrate/jqf/api/45

```http
    "mchOrderNo": "TRANS202605211530001234",
```
```http
    "appId": "6064c5c8f3e4a24e5b8e1a3c",
```

```json
    "currency": "CNY",
    "state": 1,
    "channelOrderNo": "",
    "errCode": "",
    "errMsg": ""
  },
  "sign": "A7B8C9D0E1F2A3B4C5D6E7F8A9B0C1D2"

```

### 转账状态说明

| state | 含义 |
|-------|------|
| 0 | 转账生成 |
| 1 | 转账中 |
| 2 | 转账成功 |
| 3 | 转账失败 |
| 4 | 转账退回 |

## 失败响应示例

```json
  "data": null,
```
