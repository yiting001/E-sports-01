# 关闭订单

API路径：`api/pay/close`

在线文档：https://doc.jeequan.com/#/integrate/jqf/api/41

## HTTP 示例

```http
POST /api/pay/close HTTP/1.1
Host: your-jqf-domain.com
Content-Type: application/json
Accept: application/json

{
  "mchNo": "M1640000001",
  "appId": "6064c5c8f3e4a24e5b8e1a3c",
  "mchOrderNo": "ORDER202605211430001234",
  "version": "1.0",
  "signType": "MD5",
  "reqTime": "20260521143200",
  "sign": "E5F6A7B8C9D0E1F2A3B4C5D6E7F8A9B0"
}
```

### 使用支付系统订单号关闭

```http
POST /api/pay/close HTTP/1.1
Host: your-jqf-domain.com
Content-Type: application/json
Accept: application/json

{
  "mchNo": "M1640000001",
  "appId": "6064c5c8f3e4a24e5b8e1a3c",
  "payOrderId": "P2026052114300000001",
  "version": "1.0",
  "signType": "MD5",
  "reqTime": "20260521143200",
  "sign": "F6A7B8C9D0E1F2A3B4C5D6E7F8A9B0C1"
}
```

## 成功响应示例

```json
{
  "code": 0,
  "msg": "SUCCESS",
  "data": {
    "payOrderId": "P2026052114300000001",
    "mchOrderNo": "ORDER202605211430001234",
    "state": 4
  },
  "sign": "A7B8C9D0E1F2A3B4C5D6E7F8A9B0C1D2"
}
```

## 失败响应示例

```json
{
  "code": 2000,
  "msg": "订单不存在",
  "data": null,
  "sign": null
}
```

```json
{
  "code": 2000,
  "msg": "订单已支付，无法关闭",
  "data": null,
  "sign": null
}
```
