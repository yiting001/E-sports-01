# 计全付支付平台对接技能

计全付（JQF）支付平台 Claude Code 对接技能，涵盖支付、退款、转账、分账、钱包、发票、提现、协议支付、商户进件等全场景集成指导。

## 功能特性

### 接口覆盖

| 场景 | 接口数 | wayCode数 | 示例文件 |
|------|--------|-----------|----------|
| 支付 | 6 | 32 | 1~3, 10 |
| 退款 | 3 | - | 4, 5 |
| 转账 | 7 | - | 6, 14 |
| 分账 | 11 | - | 7, 15 |
| 钱包 | 8 | - | 11 |
| 发票 | 3 | - | 12 |
| 提现 | 3 | - | 13 |
| 协议支付 | 6 | - | 8 |
| 商户进件 | 16+ | - | 9 |

### 代码示例

提供 4 种语言的代码示例（共 15 组 × 4 语言 = 60 个文件）：
- **Java**：基于官方 SDK（com.jeequan:jeepay-sdk-java:jqf-3.8.21）
- **Python**：基于 Python SDK（jeepay-sdk-python）
- **PHP**：基于 HTTP 原生调用 + 手动签名
- **HTTP**：原始 HTTP 请求/响应示例

### 核心功能

- **功能1**：支付集成指引（完整流程）— 含 wayCode 决策树、channelExtra 参数路由
- **功能1B**：通用接口对接（简化流程）— 退款/转账/分账/钱包/发票/提现/协议支付
- **功能2**：问题排查指引 — 通用错误排查 + 签名失败反误诊链
- **功能3**：进件按需对接 — 最小可用集合提示 + 接口依赖提醒 + 渠道识别
- MD5 + RSA2 双签名方式支持
- 异步通知处理规范（验签 + 幂等）
- 代理商调用支持

- 计全付退款/转账/分账/钱包/发票/提现
- 计全付协议支付/进件/商户入驻/签约
- 排查计全付错误/签名失败

## 执行流程

```
支付类请求 → 功能1（完整流程）
  需求分析 → wayCode选择 → 环境准备 → 代码生成 → 通知处理

其他接口 → 功能1B（简化流程）
  确认配置 → 接口对接 → 代码生成

进件 → 功能3（按需对接）
  未指定接口 → 提示最小可用集合
  指定接口 → 依赖提醒 → 获取文档 → 生成代码

问题排查 → 功能2
  查线上文档 → 通用排查 / 签名专项排查
```
